# 来源与使用许可

C 的机器人壳体、面罩/关节分区、可切换材质、草坪 shader、样板球几何、样板代码和接口工具为本任务原创。用户可在自己的项目中使用、修改和分发这些新增资产及其源代码，无资产费或署名要求。

鞋、32 骨架、socket、03 固定骨长接触与支撑代码来自已授权的原创 FootballCharacterHotfix：原来源声明保存在 `licenses/CHARACTER_ORIGIN.txt`，只读复制记录与 hash 在 `verification/READONLY_SOURCE_HASHES.json`。

球场继承已授权的 NEXT + stand_patch_01 原创资产：art CC0、代码 MIT；保留完整声明于 `licenses/STADIUM_LICENSE.md`。C 新材质沿用它的 get_layout/anchors/replace_material 接口和几何，不改变场地/球门尺寸。

参考方向来自父任务实际播放观察的 [《足球，就是这么踢滴》](https://www.bilibili.com/video/BV1uxzmBEE1k/)：成人瘦机器人轮廓、色壳与深色关节、蓝看台、白灰开口环顶、鲜绿草与白门细网。没有下载/提取视频内游戏模型、纹理或动画，没有复制商标/广告；不移植 VR 相机运动。

Quaternius [Universal Animation Library](https://quaternius.itch.io/universal-animation-library) 的公开页面与本机 CC0 许可已审查，本 C 候选**没有**采用或分发其资产。没有采用 GDQuest 的非商业模型/纹理，也没有复制其代码。

Godot 4.6.3、Python 与 FFmpeg 为本机工具，不随目录打包或上传。没有生成 ZIP，也没有发布竞争 EXE。
